# الإصدار المحسّن — عيادة د. محمد عبدالله الجرباني | NoDesk

الرابط المخصص: https://clinic2027dr-rgb.github.io/NoDesk/

## ما الجديد؟
- هوية طبية زرقاء وبيضاء مطورة، خط عربي واضح، بطاقات وخدمات متناسقة وتباين أعلى.
- تحسين شريط التنقل والأزرار وحجم المحتوى على الهاتف والكمبيوتر.
- روابط سريعة أعلى الصفحة للمخ والأعصاب والعمود الفقري والطبيب والحجز.
- أزرار واتساب واضحة، مع إبقاء أرقام الهاتفين 772070207 و784545908.
- فلترة تفاعلية لخدمات العيادة حسب التخصص في صفحة الخدمات.
- إرشادات عملية قبل زيارة العيادة، دون ذكر دوام أو مؤهلات غير معتمدة.
- عدم عرض قسم الخدمات الديناميكية الفارغ قبل توفر بيانات معتمدة.
- تطبيق التحسينات على جميع الصفحات مع CSS وJS مضمنين في HTML (حتى لو فاتك رفع assets)، مع ملفات مصدر قابلة للتعديل أيضًا.
- الحفاظ على صورة الدكتور الأصلية دون تحرير أو تغيير الملامح.

## طريقة رفع المشروع على GitHub من الجوال أو الكمبيوتر
1. **قم بفك الضغط** على جهازك (لا ترفع ملف ZIP نفسه).
2. ادخل إلى المستودع `NoDesk` ثم ارفع **جميع الملفات والمجلدات داخل الأرشيف** إلى جذر المستودع (بحيث يكون `index.html` مباشرة في الجذر).
3. استبدل النسخ القديمة من الملفات المتشابهة (لا تنشئ مجلدًا متداخلًا `NoDesk/NoDesk`).
4. عند رفع ملفات كثيرة، استخدم GitHub على الكمبيوتر أو تطبيق Git لرفع المجلد كاملًا. يجب الاحتفاظ بمجلد `assets` و`.github` المخفيين أيضًا.
5. افتح Settings → Pages → Build and deployment → GitHub Actions؛ ثم راقب نجاح Actions.
6. جرّب فتح رابط الموقع في نافذة خاصة أو مع إضافة `?v=2` للتغلب على ذاكرة التخزين المؤقت.

## وظائف الموقع وحدوده
- طلب الحجز يُرسل عبر واتساب فقط ولا يعني تأكيد الموعد. تأكد أن **772070207** يستقبل واتساب قبل اعتماد رابط الطلبات.
- لوحة التحكم `admin.html` لا تعمل بصورة فعلية إلا بعد إعداد Supabase وصلاحيات المستخدمين وسياسات حماية البيانات.
- لا ترفع بيانات مرضى أو معلومات سرية إلى المستودع.
- أسماء/شهادات/مواعيد أخرى لا تُضاف دون التحقق منها مع إدارة العيادة.
- مصدر CSS: `assets/style.css`، والشيفرات التفاعلية الإضافية: `assets/improvements.js`؛ ولأن CSS/JS مكرران في ملفات HTML لضمان عمل النسخة الثابتة، يجب مزامنتهما عند أي تحديث لاحق.
- هذا الأرشيف جاهز **للرفع**، لكنه لا يتضمن صلاحية النشر في حساب GitHub ولا يعدّ نسخة منشورة مباشرة.

## هيكلية النشر
`index.html` والصفحات الفرعية في الجذر؛ `assets/` للأصول؛ `.github/workflows/deploy.yml` للنشر التلقائي؛ `database/schema.sql` اختياري للنظام الخلفي.
